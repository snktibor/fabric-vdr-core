## Checked correction to the pair-alone prose

[AGENT] Read literally with freshness only for the first transaction, the paragraph's claim is false. At initial versions `a = b = 3`, let A read `(a,3),(b,3)` and write `a`, while B reads `(b,3),(a,4)` and writes `b`. The two transactions guard each other's writes, and A is successfully endorsed against the initial state. Sequential validation accepts A and advances `a` to 4, then accepts B and advances `b` to 4. `Examples.ce_future_pin_both_commit` proves these facts in the unmodified baseline.

[AGENT, proposed correction] Retain the theorem context requiring the second transaction's cross pin to be no newer than the initial version, or state that both calls are successfully endorsed against the initial state. Then the first can commit and its strict write invalidates the other's pin. The checked `at_most_one` theorem has both freshness bounds. The asynchronous `no_bifurcation` theorem instead obtains pinning from actual committed check prefixes plus honest credential checks. Neither frozen theorem is refuted by the counterexample. The paper itself was not edited.
